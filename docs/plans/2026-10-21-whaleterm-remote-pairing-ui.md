# WhaleTerm Remote 配对展示完善

## 设计与范围

复用已确认 W1 的配对展示和现有 Naive UI，通过本地二维码组件编码服务端返回的完整 fragment，不经过第三方二维码服务。启动成功自动打开配对弹窗；已启用时可再次查看或单独关闭 Remote。展示实际连接地址、到期时间和网络提示，凭证不落盘、不记录日志。弹窗可见时定时查询当前 Session 配对以跟随服务端轮换；切换 Session、关闭弹窗或卸载后清理定时器，迟到查询不可覆盖其他会话。过期时隐藏二维码并提示刷新。

移动端沿用现有安全配对持久化与展示元数据，不新增离线消息或 Claude 上下文缓存。

## 验证

- WhaleTerm Remote 定向测试与前端构建。
- 人工：启动弹码、手机扫码、再次查看、切换会话、过期刷新、关闭 Remote 后 PC 继续使用。

## 地址输入移除（2026-10-21）

点击远程管理直接启动并弹出二维码。后端在未指定展示地址时枚举启用的网卡，优先 VPN（utun/tun/tap/ppp/wg 等）IPv4，其次普通网卡 IPv4，排除 loopback、link-local 与常见容器网卡。无地址明确失败。保留显式地址 API 兼容和既有端口顺延；此为本机地址选择，不进行网络发现或 NAT 穿透。验证地址选择测试、Remote 前端检查和构建；真机可达性仍需验收。
