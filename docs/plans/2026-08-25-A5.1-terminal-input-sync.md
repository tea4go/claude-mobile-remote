# A5.1 Terminal Input Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将连接建立后的 PC 终端输入正文实时同步到所有已配对手机，并让终端和多个手机的输入继续由 PC Session Controller 统一串行交给 Claude。

**Architecture:** A3 Controller 在既有 `turn_started.text` 中发布规范化输入；A4 校验该语义并为最大合法输入提供有界输出预算；Mobile Web 严格解码事件，以 `requestId` 归并通用输入消息和 Claude 回复。所有手机连接地位相同，每连接只管理自己的命令结果，跨终端和手机的唯一排序边界仍是 Controller FIFO。

**Tech Stack:** Go 1.24、gorilla/websocket、React 19、TypeScript、Vitest、Testing Library、antd-mobile

```go
func validateEvent(event projectsession.Event) error {
	switch event.Kind {
	case projectsession.EventTurnStarted:
		if event.RequestID == "" ||
			(event.Source != projectsession.InputTerminal && event.Source != projectsession.InputMobile) ||
			event.Text == "" || len([]byte(event.Text)) > projectsession.MaxPromptBytes ||
			event.TurnStatus != projectsession.TurnRunning {
			return protocolError(CodeInvalidMessage, "invalid turn_started event")
		}
	case projectsession.EventTextDelta:
		if event.Text == "" {
			return protocolError(CodeInvalidMessage, "invalid text_delta event")
		}
	default:
		if event.Text != "" {
			return protocolError(CodeInvalidMessage, "unexpected event text")
		}
	}
	return nil
}
```

function validateEventSemantics(event: DomainEvent): void {
  if (event.kind === 'turn_started') {
    if (
      event.requestId === '' ||
      event.source === '' ||
      event.text === '' ||
      event.turnStatus !== 'running' ||
      new TextEncoder().encode(event.text).length > MAX_TEXT_BYTES

}
