# TestFlight外部测试实施计划

1. 用户检查设计，登录后台；核实组织资格、角色、协议与App记录。
2. 实现独立发布脚本与使用说明，明确构建号、输出、签名、上传及二维码生成步骤；验证参数错误与不上传的默认行为。
3. 准备测试与审核资料，确认加密合规和可供Apple验证的PC连接方案。
4. Release归档并导出App Store Connect包，验签、验证资源/配置，上传并核实处理结果。
5. 关联外测组、提交Beta审核；通过后确认并启用公开邀请链接。
6. 生成及解码验证二维码，检查公开页面，用户扫码安装验收；更新HANDOFF与测试记录。未通过审核不标记发布成功，不执行Git写操作。
