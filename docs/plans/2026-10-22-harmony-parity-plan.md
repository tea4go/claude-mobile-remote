# HarmonyOS 同步计划

1. 核对现有两端与 Harmony 差异，登记交接，更新设计和旧说明。
2. 同步既有协议版本、附件/结果解码、状态归并和回归测试。
3. 补齐原生扫码、安全存储、生命周期、选择器、语音、本地通知和文件缓存。
4. 接入 ArkUI 列表、设置、详情、草稿、审批抽屉与预览。
5. 执行可用自动化及工程构建，记录限制，提供真机验收清单并更新交接。

6. 按用户确认的 Mac 轻量方案获取官方 ARM64 6.1.1 工具链，隔离安装并提供环境检查/未签名构建脚本；实际 assembleHap 验证 ArkTS、ArkUI 和 SDK API，记录下载、版本、体积及产物。模拟器和设备验收后续独立执行。

## 2026-11-04 独立同步新版移动端
