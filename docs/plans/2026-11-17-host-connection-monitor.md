# 宿主后台连接检测实施计划

用户已确认方案（D129）。公共 Remote Server 增加可选 OnConnectionChange 通知与 RecheckConnections；通知只表示状态失效，宿主重新读取快照，回调必须非阻塞。主动探活只针对已订阅连接，每条连接最多一项，带独立控制帧标记，3 秒无对应 Pong 则关闭，关闭时取消探活。

WhaleTerm Registry 在存在服务时共用一个每秒读取本机网卡的任务，读取失败保留旧信息；地址变化触发探活和地址事件。连接变化唤醒后台任务，事件只包含会话 ID、服务状态、连接诊断与候选地址，不广播凭证。前端共用事件状态，初始化/手动操作继续查询，取消列表状态和二维码信息轮询。无服务停止后台任务。

验证：Transport 正常/静默/无关 Pong、停止与并发回归；Registry 多服务统一监测及退出；前端事件与请求竞态、Vue 编译；真实网络切换由用户验证。同 IP 路由变化和仅手机断网保留常规心跳检测，不承诺所有网络故障都在 3 秒内发现。
