# 新版移动端 UI：UI-1 基础与入口实施计划

- 日期：2026-11-03
- 状态：设计和交互已由用户确认；本计划待实施。
- 依据：`../specs/2026-11-03-mobile-ui-redesign.md`、D111。
- 本阶段：iOS 优先完成共用 React 界面的视觉基础、列表、设置与连接入口；详情、消息及抽屉留给后续 UI-2/UI-3。

## 范围和约束

建立浅色主题、导航和卡片的共享基础，改造 PC/项目/Session 列表、设置/PC 管理、配对页和离线演示入口。iOS 和 Android 共用 React 代码，因此共用 UI 的更改会影响 Android；本阶段先进行 iOS 验证，Android 在 UI-4 完成资源同步与平台验证。Harmony 按 UI-5 独立同步。

底部“新会话”直接进入新增配对；项目目录 + 只通过一个已连接、已配对且声明 `create_session` 的源 Session 新建该目录的会话。多个可用源时明确选择，不能以目录字符串推导额外授权或跨宿主能力。入口在无能力、离线、目录未知或操作处理中明确禁用并解释原因。

保留本地多配对、前台多连接、所有现有会话隔离与安全存储；筛选仅影响展示，不停止其他连接。缺少的图标预留空白位置等待用户提供；可操作项保留可见文字或明确无障碍名称，不以空白装饰替代可辨认入口。

## 执行步骤

1. **页面与主题基础**：集中定义视觉变量和卡片/按钮样式，处理安全区、可滚动页面与系统字号。延续页面转场及减少动态效果。分别核对窄屏和 393 × 852 参考视口，不绘制系统状态栏。
2. **会话列表**：在现有 `pcGroups` / `projectGroups` 派生 PC 卡、实际 cwd 项目组及 Session 卡片；默认显示全部 PC，本地筛选保留各连接。接入稳定标题、摘要、未读、最近查看、真实状态和活动时间；保留重命名、移除配对、返回后的滚动位置。长列表末尾留出固定底部按钮空间。
3. **新建和配对入口**：底部按钮调用原有新增配对导航；项目 + 从当前项目内筛选满足能力及连接条件的源 Session，单个直接操作、多个提供选择并明确来源。复用 Runtime 既有创建、回执和保存链路，显示成功或失败；详情不提供新建入口。
4. **设置与 PC 管理**：将现有入口、调试、本地保存说明、清除缓存及通知能力按新版卡片分组。保留总计 20 MiB 缓存上限、系统安全存储、清除结果反馈及平台真实通知状态。PC 移除只影响本机配对，不停止电脑 Session。
5. **连接页**：复用现有 JSON/Fragment 表单、扫码和连接状态机，按参考图更新布局。解析结果显示只读目标地址；保留空输入、失败、超时、取消、扫码权限与安全存储错误反馈。认证、订阅、快照及保存完成后才进入详情；输入值和凭证不进入日志。
6. **工程验证**：对新增视图交互及既有连接/配对路径补充定向回归；执行 React 全量测试、lint、构建及适用 iOS 无签名构建。使用合成数据在参考尺寸与小屏获取截图，检查滚动、空状态、长标题、键盘与安全区；不得将真实配对凭证或用户内容写入截图。

## 验收场景

| 场景 | 期望 |
| --- | --- |
| 零、单、多 PC 及同名目录 | PC 和真实 cwd 不混组；无配对可进入扫码/粘贴 |
| PC 筛选、离开/返回列表 | 计数对应筛选范围；连接继续；筛选与滚动位置保留 |
| 未读、最近查看、等待处理、离线 | 提示互不混淆，长标题和长路径不遮挡菜单 |
| 底部“新会话” | 直接打开新增配对，支持扫码或粘贴 |
| 项目 + 单源、多源、无源 | 只能用本项目合法源创建；多源可选择；不可用给出原因，旧会话不中断 |
| 重命名、移除会话或 PC | 操作目标正确，本机配对清理按既有语义执行，电脑 Session 保持运行 |
| 配对有效、无效、超时、取消、相机拒绝 | 阶段与提示真实；失败留在配对页；过期异步结果不能误进入详情 |
| 设置与缓存 | 本地说明和平台能力准确；清除成功/失败可见，不误删凭证 |
| 小屏、键盘、大字号、屏幕阅读器 | 控件可见可操作，图标缺失不导致操作无法辨认 |

# 单电脑默认与调试入口补充

目录创建及配对导航回归：覆盖网络切换后来源地址与返回子会话旧地址不同、端口保留、身份不符、连接失败提示、设置返回配对和动画方向，以及离开后错误清除；不修改共享协议。

区分未设置与用户选择全部；覆盖单电脑首次默认、用户选择全部跨重启、已选电脑删除回退，以及调试入口的显示和日志行为。验证 React 全量、生产构建和 iOS 资源同步；Android 与 Harmony 后续按确认的交互同步并验收。
