# C2-C Capacitor 原生能力接线计划

依据：`docs/specs/2026-09-24-C2-native-capacitor-integration-design.md`。

### 固定状态与左边缘返回（2026-10-09 真机反馈）

1. 详情标题区固定显示简短连接、会话、Turn 状态和可用时的重连按钮；长错误说明和队列提示放在滚动内容区。
2. 在详情页接入左边缘横向右滑返回列表，过滤垂直滚动、编辑输入和非边缘起点，复用现有返回转场与列表位置。
3. 加交互测试并运行移动端测试、lint、构建、原生同步与差异检查；请用户在 iOS 真机检查长消息、窄屏与手势冲突。

通过条件：消息滚到底时仍能查看连接状态及重连，左边缘返回可靠且正常滚动不误触。

### PC 编码与设置页（D76）

1. Go 公共 Pairing 增加可选 `pcId`，Standalone CLI 持久生成并复用该编码，覆盖签发、恢复、轮换和新建 Session；公共嵌入入口可选传入。补 Go 生命周期/格式测试。
2. React/Capacitor 和 Harmony 配对解码接受可选编码；原生恢复保留完整安全配对中的编码，前台重连、新建返回和 Web Fragment 保留字段。
3. 首页加入设置入口，设置页分组展示设备及本地配对，提供单会话和整设备移除并复用原生安全存储删除路径；旧版地址分组明确标注。补多设备/旧版/删除隔离测试。

### C2-C 设备与列表体验修订（D77）

1. 用统一短时长抽屉替换受库内弹簧参数控制的详情 Popup；提高最大高度并补短内容最小高度，保持待处理关闭语义。
2. 设置拆为通用入口与 PC 管理下一层；PC 管理仅列设备和状态，移除整机仍逐条清理本地安全配对；首页列表按 PC→目录→会话分组，单会话管理仍在首页。
3. 配对协议增加可选 `pcName`，由 CLI 主机名提供、嵌入宿主显式提供，接通 Go、React/Capacitor 与 Harmony 解码/元数据；旧配对回退并验证无跨 PC 目录合并。
4. 运行 Go 测试/构建、移动测试/lint/原生同步和 Harmony 可用的静态检查，记录 iOS 真机尚未覆盖的抽屉手感。
4. 执行 Go 定向 race 测试、移动端全量测试/lint/build/sync、Harmony 非 UI 解析或可用的工程构建、差异检查，记录真机未验收项。

通过条件：同 PC 多 Session 合并、不同 PC 分离、CLI 重启编码不变、旧配对可用，删除设备仅移除本地配对且不跨设备误删。

1. 固定 Capacitor 8 兼容插件版本；配置 Android 最低 SDK、iOS 相机用途说明和 Preferences 隐私声明，并禁用会输出 Pair Token 的 Capacitor 桥接日志。
2. 实现系统安全存储、普通元数据、扫码及前台事件的原生端口；设置原生平台门控，禁止浏览器实例化持久化端口。
3. 将原生恢复与多 Session Store/Runtime 连接；补齐无凭证占位、扫码入口、保存/重命名/删除/最近连接持久化，并避免原生 URL Fragment 留存 token。
4. 使用假插件端口覆盖关键流程及浏览器路径回归；执行 Vitest、lint、Web 构建、Capacitor sync 和环境可用的原生构建。
5. 更新 C2 验证记录与 HANDOFF，准确列出模拟器和真机/VPN 未验证项。设计文档交用户检查，Git 写操作另等明确授权。

### iOS 顶部安全区修复（真机反馈）

1. 为 WebView viewport 启用整屏布局，建立顶部导航共用安全区样式；让导航背景铺至屏幕顶端，标题和按钮按顶部及横向安全区定位。
2. 将详情、列表、配对导航和启动恢复提示接入该样式，保留详情 `100dvh` 高度与底部安全区。
3. 跑移动端测试、lint、构建和差异检查；请用户在 iOS 真机纵横屏核对导航遮挡和底部输入区，人工结果再写入交接记录。

通过条件：有效原生凭证跨 App 启动可恢复且按 Session 隔离；失效占位不连接；浏览器不持久化 token；本机可执行门禁通过。

### 页面转场体验改进（优先于 C2-D）

1. 在 React App 的列表、详情、配对三个视图外增加方向性转场容器，旧页退场时禁用交互，连续切换时清理旧层；首次恢复直接显示目标页。
2. 将列表滚动位置跟随页面容器保存与恢复，核对详情消息滚动、配对输入和顶部/底部安全区。
3. 为转场加入系统“减少动态效果”分支；执行移动端相关检查、构建与差异检查，并记录实际结果。
4. 请用户在 iOS 真机检查列表→详情→列表、列表→配对→返回、扫码后进入详情、快速往返、长列表滚动及减少动态效果；用户反馈后更新 HANDOFF，达到真机门禁再写 C2 验证记录。

通过条件：切页方向连贯，无旧页误触、丢失连接或明显滚动跳动；iOS 真机手感由用户验收。

### 转场节奏与软键盘遮挡（用户真机反馈）

1. 将页面 CSS 动画和退场层清理同步调至 360ms；保留抽屉自身弹簧与减少动态效果设置。
2. 用可视视口高度约束页面栈与详情布局；键盘打开时同步底部 Popup 位置和最大高度，并将聚焦输入滚入可视区域。
3. 加入可视视口模拟测试，执行移动端全量测试、lint、构建与 Capacitor 同步；记录自动化边界，请用户在 iOS 真机复核详情、配对和抽屉输入与动画。

通过条件：输入区不再被键盘遮挡、收键盘后布局恢复；切页与抽屉节奏经真机确认。

### iOS 键盘布局返工（本次真机验收不通过）

1. 移除页面栈 `visualViewport` 高度、Popup 底部偏移和聚焦滚动补偿及原模拟测试，恢复由单一 `100dvh` 决定页面高度。
2. 显式接入 Capacitor Keyboard iOS `native` resize，约束 WebView 根滚动；键盘显示时移除详情底部安全区空隙，列表、配对与消息流使用各自滚动容器。
3. 补键盘事件/样式接线测试，执行移动端测试、lint、构建和 Capacitor 同步；请用户按截图场景重新验收未聚焦、聚焦、收键盘、配对和待回答抽屉。

通过条件：未聚焦时底栏无明显空白；聚焦后输入框不被遮挡且与键盘间距正常；收起后页面位置恢复，顶部导航和内部滚动正常。

### iOS 键盘二次返工（用户真机再次验收不通过）

1. 将 Capacitor Keyboard 的延迟 `native` resize 改为 `none`，在已有 `SceneDelegate` 中监听键盘 frame 改变，以系统通知的动画参数同步缩放 WebView；处理收起、悬浮键盘和屏幕旋转。
2. 统一 WebView、原生窗口和 DOM body 的背景色，避免页面移动时露出黑色窗口底板；不改变系统输入法皮肤。
3. 执行移动端测试、lint、构建和 Capacitor 同步；能运行时补 iOS 构建，并请用户复核聚焦起始、键盘完全弹出、收起及深色系统外观。

通过条件：键盘动画开始时输入栏同步移动，不先被遮住再跳动；页面移动时不露出黑色窗口底板；关闭键盘后位置恢复。

### iOS 键盘跟随与详情滚动结构（真机反馈）

1. 将 `SceneDelegate` 通知驱动的 WebView frame 动画替换为全屏原生容器与 iOS 17+ `keyboardLayoutGuide` 底边约束；iOS 15/16 用通知驱动约束回退，保留插件 `resize: none` 以免重复缩放；核对安全区、悬浮键盘、交互式收起及背景。
2. 将详情页状态和消息放进单一全宽滚动容器，内容内缩而滚动条贴边，导航和输入栏固定；滚动到底/向上阅读保持原语义。
3. 运行移动端测试、lint、构建、原生同步与可执行的 iOS 构建检查；由用户在真机复核键盘起止与拖动、长消息、状态区、输入栏固定和其他输入场景，记录实际结论。

通过条件：键盘跟随更自然且无遮挡/黑底回归，滚动条靠屏幕右缘，状态和消息一起滚动，输入栏固定；原生手感以真机验收为准。

### 输入栏聚焦与禁用反馈（真机反馈）

1. 只在输入框当前聚焦时阻止附件/权限按钮和菜单项的按下事件转移焦点；保留触发菜单及选择权限的 click。其他底排按钮和页面外部点击不拦截。
2. 为禁用 textarea 提供覆盖输入区域的可触控反馈，按详情不可用原因显示短时提示和边框反馈；保持真实输入禁用、发送禁用。
3. 用交互测试覆盖按钮/菜单保焦、外部正常失焦、禁用触控反馈及启用后恢复；运行移动端测试、lint、构建与同步，交用户真机复核。

通过条件：附件/权限操作不关闭已打开键盘，外部点击仍可关闭；禁用输入区触碰有可感知反馈且不唤起键盘。
