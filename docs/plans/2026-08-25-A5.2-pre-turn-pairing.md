# A5.2 首轮前配对实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让新会话在首条真实消息前生成真实 Claude session ID、完成扫码配对，并允许 PC 或任意已配对手机提交第一条消息。

**Architecture:** SDK 通过 Claude CLI 的 `--session-id` 接受 Service 预生成的 UUID；resume 继续使用已有 ID。Service 在 SDK Connect 成功后立即注册同一 session 的 Channel 并签发配对凭证，Controller 额外维护“已确认 init”状态；首条真实 Query 才触发 Claude init，确认 ID 后发布 `session_started`，现有 FIFO Worker 和 wire contract 保持不变。

**Tech Stack:** Go、`claude-agent-sdk-go`、Claude Code CLI、WebSocket v1 协议、React Mobile Web、现有 Go test/race/build 门禁。
