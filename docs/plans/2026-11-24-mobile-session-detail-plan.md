# 11 月 24 日移动端会话详情实施计划

1. 公共 Go 协议接入 v13 工具摘要、父子关联、模型和会话内详情读取，覆盖新旧端快照与实时事件。Standalone 和 WhaleTerm 复用有界详情存储及现有 SDK 事件。
2. iOS 启用新协议与页面，压缩步骤行、展示子代理和回复模型、切换发送提示。保留已配对会话隔离与旧宿主兼容。
3. 验证 Go race、移动端测试和构建、iOS 模拟器。真机验收覆盖嵌套工具、长 Read/Edit、加载失败和重试、消息等待和失败、模型显示、多会话及旧 PC。通过 iOS 体验验收后同步 Android 和 HarmonyOS。

4. 补齐两个宿主的标题摘要以及事件、快照、缓存兼容，验证抽屉与详情标题、状态标签、边缘返回及代码滚动。
5. 在第二轮复验中提升 iOS 详情选中项的生命周期，修复样式及复制，并用 SDK 已提供的数据补齐工具正文。覆盖流式更新、抽屉返回和空结果。
6. 将 WhaleTerm 已有异步任务状态和后续子工具映射到原轮次，验证后台任务与前台队列并行、断线恢复和旧端兼容。构建 iOS、Windows 联调产物，并登记真机复验项。
7. 第三轮审查 WhaleTerm 主读取器和空闲读取器交接、后台续答及队列推进。复用 v14 后台状态更新 iOS 会话状态和单行加载入口，将可展开的子工具详情移到全屏页面，验证并行任务、重连和新轮次队列操作。
8. 启用 Android 共享实现，HarmonyOS 补齐 v13/v14 协商、解码、状态与详情页。验证旧版降级、同会话按需读取、跨轮任务和队列，并构建两端调试包。
