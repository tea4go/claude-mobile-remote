# iOS 配对首页实施计划

1. 仅启用 iOS 首页规则和页面级 Home 导航，覆盖普通启动、PC 选择、详情返回、设置和推送直达。
2. 更新配对卡片、会话卡片和目录标题，复用图标资源、PC 操作及目录新建。
3. 覆盖路径省略、凭证脱敏、连接和会话状态、目录创建及导航回归。运行移动端测试和生产构建，复制 iOS 资源并构建模拟器。
4. iOS 验收通过后同步 Android 和 HarmonyOS。

真机反馈复验：覆盖首页进入列表、列表发起配对、普通和定向配对右滑返回、首页和列表折叠、标签窄屏裁切及定向反馈。仅启用 iOS 修订。

测试结果2复验：验证首次自动检测及返回首页后仅手动探测，验证选择电脑和首页及关于的版本字段。

测试结果3复验：验证同机目录最近活动顺序、全宽与窄宽标签裁切、外侧省略号及 iOS 刷新按钮尺寸。

## Android 与 Harmony 同步

用户已验收 iOS。启用 Android 共享页面，完善 Harmony ArkUI 的对应页面与返回路径，运行移动端回归、Android Debug 和 Harmony API 24 构建，最后使用现有调试签名在 Harmony USB 真机覆盖安装并验证启动。

## HarmonyOS 真机反馈修订

对照 iOS 调整 ArkUI 的圆角交互、Home 图标、PC 行和会话首行。执行 Harmony 回归、API 24 调试构建及 USB 覆盖安装启动，记录真机复验范围。

第二轮 HarmonyOS 修订沿用上一轮验证流程，重点复核 PC 图标可见范围、扫码和目录图标以及两页标题。运行 Harmony 回归、编译并通过 USB 安装启动。

第三轮 HarmonyOS 修订沿用现有探活和重连链路，补齐两页各自的状态反馈，再运行回归、API 24 编译和 USB 安装启动。

HarmonyOS 首页 PC 图标统一缩至 24 vp 高，运行回归和 API 24 构建，通过 USB 覆盖安装。

三端会话状态补齐。保留既有协议，在 React 和 ArkTS reducer 中保存 PC 下发的轮次状态，驱动卡片图标，覆盖无回复快照及后续事件，并验证三端构建。
