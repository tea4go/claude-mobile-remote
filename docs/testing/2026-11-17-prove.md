# 远程控制claude功能优化

### 优化点

1. 移动端的sessionList首页，在初始化打开应用以及从后台切换到应用唤醒阶段，需要主动查询一次当前列表的连接状态。
2. 移动端的sessionList界面整体需要一个 从顶部向下滑动刷新整体连接状态的功能，用于主动查询一次当前列表的连接状态。

### 优化点2

1. 移动端的配对界面内的ip输入框，需要新增 提示功能，参考图：docs/testing/images/11-17/paring_ip_input.png

聚焦输入框时，展示下拉框显示最近的10条记录；开始输入后，则下拉框内根据输入内容进行匹配筛选；输入框失去焦点后，隐藏下拉框

### 优化点3

1. "优化点2"内的ip输入提示继续优化：
   1.1 目前点击下拉框内的选项没有反应，应当要回填到输入框内
   1.2. 提示的下拉框，建议在第一排 添加 删除 功能，清空所有历史记录，可参考docs/testing/images/11-17/search_sugestion.png

2. 移动端配对界面内的提示需要优化，目前都是toast，需要参考设计图：docs/testing/images/11-17/paring_new.png
   做成面板的形式，放在"扫描二维码"的下方，红色 ——> 错误 黄色 ——> 警告 绿色 ——> 成功 普通文本 ——> 其他普通提示

### 优化点4

1. 移动端 首页的PC切换 需求调整，设计稿：docs/testing/images/11-17/session-list-pc-expand.png
   1.1. 点击首页顶部的PC，由原来的抽屉改为 展开已连过的PC列表
   1.2. PC列表直接在首页管理，PC Item展示自己的连接状态；点击PC Item则表示选中当前PC，和原来的切换PC效果一致；左划可以操作编辑和删除；去除 "设置"页面内的PC管理
   1.3. 编辑PC Item跳转至新的界面：docs/testing/images/11-17/pc-edit.png，可以编辑别名，和ip。输入框的组件可以使用antd mobile Input，我认为输入框可以不参考此设计图，我觉得设计图内的输入框不符合移动端的输入设计标准；确认按钮固定在最下方；

2. 移动端 配对界面 需求调整，设计稿：docs/testing/images/11-17/session-paring.png
   2.1. 配对界面里展示 历史已经配对过的PC，纯展示，点击PC Item后，在IP输入框填入此PC的IP即可
   2.2. 按钮组固定在界面最下方
   2.3. tip/操作状态等等 放在按钮组的上方即可
