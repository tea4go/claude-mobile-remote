### 修复进展与复测

- 配对：截图中 PC 已成功弹出验证码，会话连接日志则停在 WebSocket 建连阶段。11 月 17 日 WhaleTerm 已在固定 7330 入口增加已配对会话的稳定路由，并加入后台连接探活。同一轮稳定入口改动未涉及 Standalone CLI 服务端。Harmony 此前只对已保存记录使用稳定路由回退，现将扫码和六位码首次配对也接入现有回退，并在取得有效快照后保存实际路由。日志可记录系统数字错误码。用户原始故障的触发条件尚未复现。
- IP 历史：改为有滚动上限的左对齐下拉列表，支持选择与清空，无匹配时收起。
- WhaleTerm：验证码弹窗的目标会话标题限制为单行，超宽显示省略号，工作目录继续换行。
- 已验证：Harmony 96 项测试、22 文件逻辑检查、API 24 Debug HAP 构建、ZIP 校验及 USB 覆盖安装启动。WhaleTerm Vue 组件编译及前端生产构建通过。运行中的 WhaleTerm 在本机上，快速配对入口、稳定会话入口和当前独立会话入口均返回 HTTP 101。
- 真机复测：分别扫码和输入新六位码，确认进入正确会话并显示状态。聚焦 IP 框，确认筛选、点选和清空。更新桌面应用后用长标题会话打开验证码弹窗，确认标题单行且目录仍可见。
