## 已验证行为

- 完整 Pairing 仅传给安全端口，普通元数据只保留会话 ID、名称和上次连接时间。测试内存端口只用于自动化，不提供产品存储实现。
- 扫描 Fragment 与 JSON 复用既有 Pairing 校验；取消、过期和无效输入不写入存储。
- 恢复多个记录时只把有效、与元数据 `sessionId` 一致的凭证交给连接候选；缺失、损坏、错绑与过期记录进入需重新配对，过期安全记录尝试清理。
- 同 ID 换凭证保留本地名称；安全写入失败最多留下无凭证元数据；删除先移除安全记录，失败时不误报完成。
- 前台计划覆盖全部有效 Session，过期者需重新配对；注入式前台事件读取最新配对，并可取消监听。计划本身不建立 WebSocket。
