# Offline demo — Beta review instructions

Applies to version 1.0, build 3 and later builds retaining this demo.

Claude Mobile Remote is a companion for Claude sessions hosted on the user's computer. Normal use requires WhaleTerm or the standalone companion and a reachable LAN/VPN. No app account is required.

1. On the pairing screen tap “体验演示（无需连接电脑）”. Existing users can also find this entry in Settings.
2. A persistent banner identifies the offline simulation. Send any short text to see a fixed streaming reply and progress.
3. Tap “演示审批”, then Allow once or Deny. No real file is accessed or command executed.
4. Tap “演示问答”, select an answer and submit to complete the simulated question flow.
5. Send another message and use Stop during streaming. You can send again afterwards.
6. “重新开始” resets the simulation; “退出演示” returns to the normal app.

The demo uses scripted data. It does not call Claude, connect to a computer, validate QR/WebSocket connectivity, upload attachments, or execute commands. Real functionality remains available through normal pairing. Demo messages are kept only in memory and discarded on exit.

The developer has verified the offline demo on a physical iPhone. Apple acceptance of this review method remains subject to review.
