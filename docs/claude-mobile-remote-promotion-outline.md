# Claude Mobile Remote 产品介绍大纲

> 用途：内部推广。本文为内容大纲，推广入口和支持渠道待确定后补充。

## 一、产品概述

Claude Mobile Remote 的产品定位：通过移动端连接电脑上的 Claude 会话，支持用户在离开电脑后继续关注任务进展并参与必要交互。

说明会话和执行环境保留在电脑端，移动端承担查看和操作入口的职责。

## 二、建设背景与主要痛点

- Claude 执行较长任务时，用户需要持续关注任务状态。
- 审批或问题反馈可能阻塞任务，需要用户及时响应。
- 用户离开工位后，不便查看电脑端会话及处理待办。
- 使用多台电脑或多个项目时，会话状态分散，切换和跟进成本较高。

## 三、主要功能

- **会话配对与连接**：通过扫描二维码连接电脑端会话。
- **任务进度查看**：查看当前会话状态、消息及执行进度。
- **移动端交互**：发送消息、回答问题、处理审批及停止任务。
- **多会话管理**：查看和切换已配对的电脑、项目目录及会话。
- **远程新建会话**：在满足连接条件的项目目录下新建会话。
- **图片等交互能力**：结合移动端设备完成图片相关操作。

## 四、与 WhaleTerm 的组合使用

介绍两者的职责分工及基本使用流程：

1. 在 WhaleTerm 中打开 Claude 项目或会话，并开启远程控制。
2. 使用移动端扫描对应二维码，完成配对。
3. 在手机上查看任务进展、处理交互，并按需在项目目录下新建会话。
4. 返回电脑后，继续使用 WhaleTerm 查看和操作同一会话。

## 五、独立使用方式

介绍 Standalone CLI 的基本定位：在不依赖 WhaleTerm 的情况下，由命令行工具启动和管理 Claude 会话，再通过移动端扫码连接。

## 六、连接方式与数据边界

- Claude 会话上下文和操作执行保留在电脑端。
- 移动端与电脑通过网络互通的局域网或 VPN 建立连接。
- 移动端主要接收当前状态、待处理事项及配对后的新增消息。
- 产品不提供公网实时中转或云端会话中心。

## 七、适用场景与预期价值

- **长时间任务跟进**：减少对电脑端的持续关注。
- **任务中途交互**：在移动场景下及时处理审批和问题。
- **多项目协作**：集中查看和切换已配对的电脑及项目会话。
- **工作连续性**：在电脑和手机之间延续同一会话的操作流程。

## 八、现阶段限制与待完善事项

- 使用时需要保证手机与电脑网络互通；跨网络连接通常需要 VPN。
- 电脑及对应会话需要保持运行。
- 移动端不提供电脑端完整历史上下文的管理能力。
- 移动端队列功能尚未完善，相关入口暂时隐藏。
- iOS 推送暂时停用，退出 App 后无法接收新事件通知。
- Android 已完成新版同步和构建，仍需完成真机逐项验收；HarmonyOS NEXT 待后续适配。
