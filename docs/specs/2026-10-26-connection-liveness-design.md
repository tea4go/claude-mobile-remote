# 移动端连接存活检测

原因：PC控制帧ping/pong由WebView自动处理，JS无法观察；readyState不证明链路可达，offline/前台监听目前未主动探活。

v6使用ping/pong空payload，sessionId精确绑定、seq=0，不干扰输入队列和单在途操作。订阅成功后每10秒发ping，5秒内未收到pong即断开；正常业务事件不代替pong。每条连接仅一个探测在途，close/error/重连清理定时器。恢复前台立即检查超时再探测；offline立即断开，online仅触发探测，不等同可达。旧宿主降级v5/v4/v3/v2，无应用探活能力，仍保持已有手动重连。

日志固定记录探测发送/响应/超时及阈值，禁止正文、凭证或原始异常。用户无需发送消息即可在前台约15秒内发现静默断网；系统后台暂停不作实时承诺。三端核对见D95。
