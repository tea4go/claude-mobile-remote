# iOS 网络连接反馈修复

依据 2026-10-26-ios-net-connect-result.md 与本轮确认，沿用 D80 自主实施，iOS 最终验收后同步其他原生端。

## 已确认问题与诊断边界

ProtocolClient.connect 没有应用侧建连/握手超时；onerror 等待系统 close。App.openPairing 与 scanAndSave 在收到 snapshot 前保存并打开详情。Transport 有 5 秒认证读取期限，但认证后取消期限；没有公开连接统计。Info.plist 已包含本地网络用途说明与 NSAllowsLocalNetworking，尚无证据证明是 ATS 配置故障。

手机与 PC 地址不同本身不能证明网络故障；主副网之间的路由、无线隔离、防火墙、二维码地址和 iOS 本地网络权限需实际定位。未知错误仅给出可能原因，不把 WebSocket 1006 伪装成精确权限或防火墙结论。保留 VPN/显式地址直连；不做发现、穿透或 Relay。

## 配对与连接

扫码/粘贴解析后留在配对页，显示正在连接 PC、认证、同步。候选凭证仅内存，使用同一条 ProtocolClient 完成 hello/subscribe/有效 snapshot 后保存到安全存储并进入详情，避免探测连接与正式连接重复。失败/取消不写入新配对、不替换既有同 Session 凭证；重试重新建立连接，取消和过期回调不能导航。保存失败关闭候选连接并提示，不显示配对成功。重复扫码按 Session 更新，其他 Session 连接不受影响。

建连 8 秒，认证 4 秒，订阅/首快照 4 秒，单次尝试总上限 15 秒；协议降级共享总预算。close/error/超时/取消清除全部计时器与旧回调。已连接后连接故障保留原有消息与命令结果未知语义；不自动重发输入。指令受理等待限制 15 秒，附件仍有 30 秒上限；超时释放忙碌状态并断开，防止迟到结果串线。Claude Turn、审批等待不是连接超时，不套用此期限。

## 诊断面板

配对页和设置提供网络诊断入口，可查看每次尝试的阶段、时间、耗时、目标主机/端口、固定错误码及建议；支持重试和清除。只保留进程内最近 100 条结构化记录。URL 只显示 scheme/host/port，剥离 userinfo/path/query/fragment，禁止记录原始扫码负载、凭证、完整协议帧、消息正文与底层错误文本。详情连接状态可从设置检查。用户可据此核对 iOS 系统本地网络权限、PC 监听地址、VPN、主副网路由及防火墙。

## PC 观测与 WhaleTerm

公共 remote.Server 提供按 Session 查询的统计与最近有界诊断，记录握手拒绝、认证成功/失败、订阅成功与断开，不记录 token/请求正文。在线数仅计已认证且订阅成功的连接，断开/取消订阅/关闭后扣减，认证失败不计数。无设备 ID，界面明确称“在线连接”，同设备多连接可能重复，不声称去重设备数。

WhaleTerm 复用现有 Remote Service/Registry 与 Wails 当前会话查询，展示在线连接数与最近连接结果；面板打开时短周期刷新，离开停止，按 generation 丢弃过期响应。PC 二维码可在本机网卡地址间选择，保留实际分配的端口、sessionId 与配对凭证；二维码与复制内容使用同一候选地址，避免自动优先 VPN 网卡而手机不可达。服务器通过 WebSocket 控制帧每 10 秒探活，已订阅连接连续 30 秒无 pong 则移除在线统计；活跃但空闲会话不会误断。公开诊断 API 为宿主 Go 接口，不增加匿名网络诊断端点、不扩大配对授权。二维码公布地址与实际监听信息供 PC 核对。

## 三端契约与兼容

wire v4/v3/v2、Pairing v1、Session/Turn 状态均保持不变。新增阶段/超时原因仅为端内连接诊断纯数据；iOS/Android 的定时器和 Harmony 的 ArkTS 定时器均可等价实现，同用 hello/subscribe/snapshot 成功标准。PC 统计不要求客户端设备标识。共用 React 代码会随构建自然更新，Android/Harmony 原生同步与验收在 iOS 通过之后。DECISIONS 记录核对结论后实施。

## 验证

假时钟覆盖各阶段/总体期限、协议降级、取消/旧回调、保存前不导航、失败不落盘、同 Session 重配与跨 Session 隔离。Go 覆盖认证拒绝、1→2→1→0 连接、取消订阅/重订阅、关闭与并发查询。移动全套 test/build/lint、Go 定向/race、WhaleTerm 定向测试/前端构建和 iOS 编译。真机需测试同可达网段、原主副网、拒绝/恢复本地网络权限、错误地址、两设备及 PC 关闭；实际网络问题的解决需真机证据，不用自动化替代。

## 扫码目标地址补充

扫码解析成功后，在配对页直接展示目标PC地址（scheme、IP/主机名和端口），无需展开诊断；连接失败或取消后仍保留，下一次有效配对覆盖。复用脱敏函数，不展示凭证、路径、查询及fragment，不把PC目标地址标成手机本地IP。不增加原生网络权限或修改共用契约。

## 应用内调试面板（用户确认的后续修订）

用户确认增加设置开关与全局悬浮入口，开发/Release共用，替代此前禁止App内面板的部分。保留Safari检查。最近200条仅内存保存，固定动作/连接阶段/异常类别和脱敏scheme/host/port，不收集Session ID、凭证、正文、协议帧或原始错误/堆栈。支持清空、复制、导出和失败提示。默认关闭，关闭停止新增记录，已有记录退出进程清除；开关不持久化。

实施：有界存储及异常监听 → 复用连接记录、补动作记录 → 设置与悬浮面板 → 隐私/容量/交互测试、生产构建、仅同步iOS。不拦截console或底层网络，不完整映射Safari，无新依赖，无协议/状态/Pairing契约变化；其他原生端待iOS验收。

iOS复制通过系统剪贴板（仅本机、5分钟过期），导出通过UIActivityViewController分享临时UTF-8文本文件，完成/取消后删除临时目录；用户明确保存的导出文件由用户管理。接口可选，不改共用协议；非iOS保留浏览器复制/下载路径，其他原生端未验收。

## 真机日志反馈优化

依据images/1026/mobile_log.png：日志增加固定事件码/级别、进程内连接编号与尝试次数、阶段及阶段耗时、总耗时、协议版本、超时阈值、WebSocket readyState、close code/wasClean及固定关闭码解释。不收集close.reason或异常原文。记录主动关闭、手动重连、协议降级和错误后的close事件，旧连接延迟事件只写其原尝试记录、不改变新连接。现有客户端无自动重试，断开记录明确等待手动重连，不实现或暗示新重试策略。

面板列表倒序实时更新、毫秒时间、紧凑工具栏与行距；左下入口根据可见输入组件和visualViewport动态避让，键盘/输入区变化时更新。验证覆盖关闭元数据、error→close、重连关联、超时、敏感字段过滤、倒序和入口布局计算，构建同步iOS并重打IPA。
