# 11 月 24 日移动端会话详情设计

用户确认 iOS 先行，真机验收后同步 Android 与 HarmonyOS。协议兼容见 D134。

## 步骤与详情

- 步骤抽屉按内容排列，保留触控面积。`Agent` 和 `Task` 显示描述、状态和下属工具，可展开查看。PC 按 SDK 的 `parent_tool_use_id` 关联子工具，子代理文本不进入主回复。
- v13 工具事件和最近一轮快照只传身份、状态和摘要。PC 在原宿主生命周期内按轮次和工具 ID 保存有界、不可执行的文本详情，按每条 128 KiB、每会话 8 MiB 和 256 条限制，淘汰最早的详情。工具输入采用选定的展示字段，工具结果只取 SDK 文本。旧协议继续收到既有 16 KiB 结果。
- 使用原已认证且已订阅的 WebSocket 请求详情，使用 Session ID、轮次 ID、工具 ID 和独立请求关联。读取不占用执行队列或事件序号。缺失、断线、超时和淘汰均可在页面显示读取失败。有效旧宿主使用其已有摘要和有界结果。
- 详情独立全屏，进入时加载，失败时可重试。保留代码、命令、文件内容和 diff 的原始换行及横向滚动，使用现有安全 Markdown 渲染可识别的 Markdown。正文只在打开页面时驻留内存，离开页面取消等待。旧缓存读取时保留步骤身份和状态，去除已写入的工具结果正文。

## 消息与模型

- PC 确认接收本机发送的输入时显示「等待处理」。按相同 request ID 识别首个思考、工具、回复、审批或轮次终态并结束提示。排队、引导、断线结果未知继续遵守既有事件的语义，历史恢复不重放等待提示。
- 使用顶层 SDK AssistantMessage 提供的实际模型，在相应 Claude 回复标题展示。最近一轮有序快照携带对应文本的模型，历史记录或旧宿主缺字段时按已有标题展示。

工具标题采用工具名与 PC 按工具用途选取的有界 titleSummary，抽屉和详情共用。详情使用水平进退动画和左缘右滑返回，保留抽屉位置，支持减少动态效果。标题右侧展示状态标签。

v13 客户端连接时可用查询参数 `toolTitles=1` 声明支持标题。PC 仅向声明能力的 v13 连接发送最多 160 个 Unicode 码点的单行摘要，WhaleTerm 的 7330 入口转递此能力。首版 v13 的严格字段校验仍可正常工作。

## 异步子代理与第二轮复验

- WhaleTerm 复用已有任务跟踪、空闲 SDK 读取和宿主队列。v14 的后台状态按启动轮次与工具 ID 归并，父代理与下属工具即使跨轮收到仍关联原轮次。新消息在前台轮次空闲后由既有队列处理。后台通知及子代理内容不写入下一轮的输入或正文。
- v14 快照包含有界的后台任务与近期子工具状态，旧版快照省略扩展，旧版客户端收到同序号的兼容通知。只有宿主观察过的任务和正文可查询。
- 详情页的选中项由会话消息区域持有，流式分组变化或轮次结束期间保留页面与抽屉状态。子代理面板默认折叠，标题可展开第二级子工具；普通工具点整行访问详情。恢复步骤左侧的状态线，详情标题单行省略。会话列表仅在 iOS 去除目录之间的分隔线，iOS 配对首页 PC 行只在按压时高亮。
- PC 优先显示已由 SDK 提供的 Read 内容、Edit 补丁、Write 内容、AskUserQuestion 问答以及 Bash 命令和输出。有一般执行提示时保留提示。现有结果请求和字节上限继续适用，不追加文件系统读取。Bash 代码和输出可分别复制，思考过程与会话回复共用 Markdown 渲染。页面分别提示无正文、结果截断、过期或断开等状态。

## 第三轮 iOS 复验修订

- iOS 按 v14 活跃后台任务显示「正在执行子任务」。主轮次结束后仍显示后台运行，同时保留主轮次终态、取消目标与宿主 FIFO 语义。已断线或终止的会话不将缓存显示为实时任务。
- 空闲 SDK 读取器根据已登记任务的完成通知将它随后读到的顶层续答关联到原轮次。收到该响应的结果后清空关联。迟到正文进入已订阅连接的事件流，较新的轮次继续持有自己的快照和取消目标。SDK Client 仍由空闲读取器和队列新轮次依次读取。
- 步骤抽屉的子代理使用单行入口和运行加载动画。子代理全屏详情包含可折叠的子工具列表，默认折叠，展开原地按需读取该子工具的输入和结果。打开详情时持续更新子工具状态。

用户确认同步 Android 和 HarmonyOS。Android 启用共享实现，HarmonyOS 使用 ArkUI 页面和现有配对连接实现等价交互，两端协商相同的 v14，旧 PC 继续降级。
