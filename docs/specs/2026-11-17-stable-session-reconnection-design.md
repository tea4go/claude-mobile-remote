# 已配对会话稳定重连设计（用户已确认）

## 问题与目标

WhaleTerm 为各 Remote 按启动时可用端口分配地址，手机保存的是当时的地址；服务重启或其他会话启停后，同一 Session 可能换端口，旧端口也可能属于其他 Session。2026-11-17 单会话手机日志显示旧端口 7331 建连失败，PC 端同一 Session 目前在 7333 且持有有效凭证。目标是在该 Session 的 Remote 已启动、PC 地址可达且原凭证仍有效时，不因端口变化要求用户重新扫码。

## 方案

复用 WhaleTerm 现有 7330 入口，新增与快速配对独立的固定 WebSocket 路径作为已配对会话入口。手机将保存地址的主机部分用于该入口，仍以原会话协议发送包含 Session ID 和 Pair Token 的 hello。入口只根据 hello 中的 Session ID 寻找当前活跃 Remote，并把连接转交对应 Remote，原有 Remote 仍负责校验凭证和全部操作；不返回会话列表，不创建会话，不发放或延长凭证。未知 Session、无效凭证及不可用服务不得暴露其他 Session 信息。限制握手大小、等待时间和并发，禁止记录凭证与原始帧；连接关闭、服务关闭及取消要释放转发资源。

新 iOS 在原地址连接失败或鉴权被拒绝时，可在同一主机尝试固定入口 `/session/v1`；仅成功认证并取得有效快照后才把稳定入口写入安全存储，之后直接重连该入口。自动回退仅用于 `ws`，不把 `wss` 降级成明文。固定入口失败不能单凭它断言凭证过期，也不能自动重发未知结果的操作。旧 WhaleTerm 或入口不可用时保留旧地址和凭证，显示连接失败与原有重新配对路径。未知或过期凭证不得以路由代替鉴权；不能自动尝试其他主机、扫描端口或向其他设备发送凭证。

原端口、扫码和快速配对继续兼容；单 Session Server、唯一 Host/Client、输入串行、会话隔离及现有会话协议语义保持不变。固定入口随 WhaleTerm 首个 Remote 启动、最后一个关闭而关闭；7330 被占用时保留现有可见错误和旧方式。PC 地址本身变化、Remote 未启动、VPN 不通、凭证过期或撤销不在自动恢复保证内。

## 契约与验收

固定路径和握手行为涉及三端共同接入约定：iOS、Android 的 React 客户端及 Harmony ArkTS 均可使用现有 WebSocket/JSON 实现；不得依赖浏览器专属能力。用户确认本设计后记录 DECISIONS，并先完成 iOS 与 WhaleTerm，iOS 真机通过后再同步 Android 和 Harmony。

测试覆盖同会话端口变化、旧端口被其他 Session 占用、错误/过期凭证、不同 Session 隔离、多连接、Remote 启停及入口关闭、旧宿主和入口不可用降级、保存失败、握手限额、未知操作结果不自动重发。完成自动化和构建后，由用户真机验证重启或改变会话启动顺序后的重连；不能用本机模拟替代真机验收。
