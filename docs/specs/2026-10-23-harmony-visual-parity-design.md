# Harmony 界面对齐 iOS / Android

- 状态：用户已检查通过，开始实施。
- 基准：当前 apps/mobile/src 的实际页面、ProjectSessionList.css、app.css、MessageComposer.tsx 与 BottomDrawer.css。
- 目标：统一信息层次、页面结构、尺寸和视觉，不以缩小预览画布代替页面修复。

## 1. 视觉基准

| 项目 | Harmony 对齐方式 |
| --- | --- |
| 背景与卡片 | 页面 #f2f2f7，卡片白色，圆角 12vp，主色 #1677ff，次级文字 #6e6e73 |
| 字号 | 列表页标题 22fp，会话标题 16fp，摘要 13fp，目录 12fp，状态与时间 11fp |
| 间距 | 内容左右 16vp，卡片内左右 12vp，文本间距 4vp；列表每行至少 100vp，与当前移动端一致 |
| 按钮 | 导航和辅助操作使用透明背景、文字或图标，显式设字号和内边距；主要提交保留主色，危险操作用红色 |
| 点击区域 | 导航/更多等操作保留至少 44vp 点击区域；图形本身较小，不把所有点击区域都画成实心胶囊 |

数值以 ArkUI vp/fp 表达，按相同逻辑宽度对照；系统字体和原生弹窗允许平台差异，不承诺像素完全一致。

## 2. 页面调整

### 会话列表

- 顶部标题和轻量设置入口；新增配对作为列表末尾的白底主色文字入口，避免重复顶栏入口。
- 按稳定 PC 身份分组，旧配对回退连接地址；组内保持已有顺序，不引入目录嵌套。
- 同一电脑的会话共用圆角白色列表容器，行间细分隔线。
- 左侧依次标题/未读点/刚刚查看、单行摘要、单行目录；右侧状态和简短时间，再放透明更多按钮。
- 长标题、路径和状态截断；保留重命名、移除、最近查看及滚动恢复。

### 设置

- 与移动端一致使用通用列表首页，PC 管理进入下一层。
- 提醒、清缓存和 PC 管理采用白底列表行；PC 管理只显示机器名、汇总连接状态和操作，不展示机器编码或原始连接地址。
- 保留已有确认对话框及删除语义。

### 会话详情

- 返回、标题、紧凑连接/任务状态、更多统一在固定标题栏；状态信息采用中文并处理长标题。
- 重连入口靠近状态；待处理与队列入口用紧凑样式，消息区占剩余空间。
- 统一消息字号、边距、背景和圆角，保留 Markdown、工具结果、图片预览和最新消息入口。

### 输入区

- 使用与移动端相近的白色圆角输入容器，输入框及紧凑工具栏。
- 图片/拍照/文件收进附件菜单；语音、权限模式、新建、发送/停止通过紧凑控件呈现，避免多排大胶囊。
- 保持草稿、附件、权限模式、录音取消和提交状态的现有行为与启用条件；所有图标操作有可访问名称。
- 窄屏时避免工具栏横向溢出，录音状态提供完成和取消入口。

### 审批抽屉

- 白色面板、顶部标题/轻量取消操作、正文内部滚动，沿用取消当前 Turn 的确认语义。
- 工具内容独立浅灰块；审批操作显式设尺寸、字体和布局，窄屏可纵向排列，避免三个默认按钮挤成一排。
- 统一问题选项和回答提交样式，不改变 actionId、回答内容或可执行条件。

## 3. 范围与验收

- 仅改 Harmony 页面/组件、端内展示辅助、预览虚构数据和文档；不改三端通信契约、Session Host、FIFO、配对存储、签名和 SDK。
- 预览补充两台电脑、多会话、长标题/目录、未读与近期查看、不同状态；详情检查审批前后、设置层级和窄屏工具栏。
- 运行现有 Harmony 测试、真实 HAP 编译与 PreviewBuild；用实际 ArkUI 预览核对列表、设置、详情、输入及审批，记录未验证的原生交互。
- 预览不支持键盘转发，文本输入/软键盘适配必须标记为设备待验，不能用截图冒称通过。
- 用户人工验收：按钮视觉是否合适、列表是否接近现有两端、详情/输入/审批是否协调。
