# Apple Beta审核演示服务部署包

状态：用户已确认按设计继续，示例保持简单。目标Ubuntu20.04 x86_64；文件下载前缀https://edo.iwhalecloud.com/verfiles，服务器目录/home/share/verfiles。WSS使用/verfiles/review/ws，Nginx映射到本机独立演示服务/ws；私有数据不放下载目录。

## 范围

用户提供服务器并自行部署。交付明确标为模拟演示的独立Host，复用现有interactive FakeHost和真实Session Controller、配对、WebSocket。它不调用Claude、不执行shell或读取真实项目，不宣称完整真实模型能力。Apple是否接受该演示仍取决于审核；正式备注披露模拟范围并辅以真实操作视频。

本服务不接管WhaleTerm，不是Relay，不建设云端Session中心。手机继续使用当前App扫描既有协议二维码，无新增wire字段；iOS/Android/Harmony均使用同一配对/消息契约。

## 交付内容

- Linux amd64和arm64二进制及SHA256清单，独立cmd/review-server入口，禁止调用真实SDK Host。
- systemd单进程服务模板、配置样例、Nginx TLS/WebSocket代理模板；默认监听127.0.0.1，公网仅由HTTPS/WSS代理暴露。模板不覆盖服务器已有站点，域名及证书路径由部署者填写。
- 部署/停止/更新/轮换说明、本机健康检查及外网验收步骤、英文审核操作说明模板。
- 配对数据和二维码仅部署后在服务器私有目录生成，文件权限0600、目录0700；不放预生成通用凭证到压缩包，不在服务日志打印二维码/配对负载。二维码可经SSH下载后私下交Apple，不提供匿名下载凭证接口。

## 生命周期与演示流程

- 一个演示Session、一个FakeHost、一条串行输入队列；启动后等待手机扫码。
- 清楚显示模拟服务名称，回复和工具结果明确为合成内容。先支持当前interactive脚本：发送任意非敏感短句、固定回复/工具审批、单选多选问答、取消和下一轮。附件仅作为受限传输能力，不声称真实模型读取；须检查当前Host能力并在验收说明列出缺口。
- 配对凭证有效期默认7天；重启保持同一未过期身份及凭证，过期或显式轮换生成新私有文件/二维码。轮换立即使旧连接和凭证失效。停止服务即可撤掉审核访问；新二维码需同步更新Apple备注。
- 使用现有心跳、认证、大小上限及Origin校验，不以*放开Origin。多客户端共享同一演示Session须在说明披露，避免把它作为公共测试服务。
- 日志仅固定启动/停止/错误类别，不记录输入、协议正文、凭证、路径或原始请求。代理关闭该站点请求访问日志；运行用户非root，仅能写专用私有数据/受限附件目录。

## 验证和边界

测试真实WebSocket认证、订阅、脚本交互/审批/取消、重启恢复、过期轮换与日志脱敏；gofmt、定向Go测试/race、Linux双架构交叉构建及包校验。本机测试不代替用户部署后的DNS/TLS/WSS/手机验证。打包内容无私人视频、凭证、证书或用户配置。

不改App、不重新上传IPA、不自动部署、不自动提交Beta审核。公网部署由用户操作；部署后核验再填写实际审核材料和提交。
